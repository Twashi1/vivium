## Build

1. Clone the repository and cd in
> `git clone https://github.com/Twashi1/vivium; cd vivium`
2. Run cmake to build
> `cmake --preset default`
> `cmake --build build`
5. Run editor
> `./build/editor` or `build/editor.exe`

## Dependencies

Using [vcpkg](https://github.com/microsoft/vcpkg) to install dependencies
- Vulkan SDK v1.4+
- Lua v5.4+ 
- GLFW 
- GLM 
- STB image
